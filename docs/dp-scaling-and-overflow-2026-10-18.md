# DP 比例技能、逐段破盾与属性破坏上限

## 技能 DP 比例

仅 AttackByOwnDpRate 自动启用。来源 Value1/Value2 优先读取游戏，缺失时用资料库 value[0]/value[1]。分别是 0 DP / 满 DP 的独立倍率：

`factor = at_zero + (at_full-at_zero) × clamp(current_dp / max_dp, 0, 1)`

本地 FMikotoSkill52 为 [1.75,1]；AliceASkill52 等为 [.6,1.5]，无需按技能名硬编码正向或反向。超过满 DP 按满值封顶。自身 DP 与上限来自资源快照；参数可改，仅相关技能显示专用参数区。固定使用技能开始时 DP，不预测技能内回复后的动态倍率变化。

## 属性上限

参数 max_dr 表示本技能允许增长到的上限。对应已满元素量表的技能可预加 300 个百分点；不匹配则保持普通上限。每段实际增量为 `min(理论增量, max(0, 上限-当前破坏率))`。当前已经高于本技能上限也不下调，所以 350% 打普通上限 300% 时仍以 350% 计算伤害，增长为零。

## DP → HP

按本体和追加连击顺序模拟。2026-10-19 按用户实测修正：每段先结算伤害，再判断盾是否已清空；破盾当段即可增长破坏率。超过剩余 DP 的伤害仍丢弃，不打 HP；后续段按更新后的破坏率打 HP。未破盾的段不增长破坏率。分别应用 DP/HP 特攻，已读取的承伤池相关加攻／减防差异也按池切换。逐段报告列出原伤害、实际扣除、丢弃溢出、承伤池与破坏率变化。

连击权重如 .25 表示本体完整基础伤害的 25%，其破坏率理论增量为技能破坏倍率 × .25 × 敌人系数 × 增长倍率。追加段不影响饰品的本体 Hit 数插值。主段均分破坏增量的规则保留。

敌人 HP 用尽后后续段不再扣血或增长。尚未支持多层盾自动切换；检测到额外 DP 槽时不默认启用跨池模拟。敌方资源、状态与自身资源都固定为填表快照，不预测行动中新增的 Buff、回血或新的盾。

跨池伤害是未衰减、无浮动基准情景。随机浮动可能改变破盾的段数与丢弃量，因此禁用原固定权重概率曲线及简单 0.9–1.1 总伤害边界；纯 HP 固定承伤池模式仍可显示原概率曲线。

验证覆盖：正反向 DP 插值及过量 DP、精确破盾与溢出、末段破盾后追加连击、DP/HP 特攻差异、HP 耗尽、已超普通上限时保持破坏率、对应属性继续增长，以及界面参数与曲线停用。
