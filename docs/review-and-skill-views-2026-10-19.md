# 本轮检查与交付

## 破盾结算

逐段模拟先计算并扣除该段伤害，再检查 DP 是否为零。破盾当段开始获得破坏率，后续 HP 段使用更新后的破坏率；溢出 DP 的伤害仍不进入 HP。精确破盾同样生效；未破盾不增长，超出破坏率上限的部分截断。新增/更新了溢出、精确破盾、追加段、承伤池加成与上限测试。

## 检查范围与结构整理

重点复查数据读取 → 条件解析 → 自动填充 → 预添加覆盖 → 逐段伤害，以及状态面板、资料卡片之间的一致性。保留原有模块边界，没有为整理而重写内存采样、敌人预测和行动记录。

- 条件判断集中在 `battle_conditions`，来源覆盖和活动状态判定集中在 `status_rules`。
- Buff 试算与伤害自动填充共用状态活动判定；修复 remaining=None 的比较异常，未知期限不当成已过期。
- 资料页的 GiveDebuffUp / GiveDefenseDebuffUp 属于施加者增益，已纠正分类。
- 新增 `skill_views` 作为纯展示模型，保留原始父子关系，切换场景时保留公共效果，使用子技能自身的 hits / hit_count / sp_cost。
- 资料页同一技能用按钮切换条件/形态，当前只展开一个场景；原始参数仍可折叠核对。没有按名称盲目合并进化技能或删除原始变体。
- 忽略本地 `.idea/`，不将 IDE 配置提交。

## 网站参考限制

按用户要求访问 https://hbr.quest/：静态读取只返回需要 JavaScript 的提示，浏览器读取连续超时，公开 HTML 直接请求返回 HTTP 403。因此未声称成功检查其当前交互或复制其源码。本轮采用用户描述的“技能卡片内切换变体”模式，并以本地 hbr.quest 原始资料与既有截图为依据；日后可在站点可用时进一步核对视觉布局。
