# 连续预告与行动轴保存

移除非指令选择阶段的预测入口屏蔽。EnemyPreview 按敌人保存当前候选；玩家行动时仍使用当前状态重新预测；敌方排队时保留同一行动表的原始进度，开始执行后锁定整组候选，直到其行动条目清空或回到指令选择。不同敌人的锁定独立。执行期间不闪烁。未支持的状态仍显示未知，不长期缓存失效规则。

行动记录默认隐藏，可嵌入主界面展开，不影响采集、伤害统计、详情或 JSON 导出。source 在正常结束且日志关闭后发送 battle_end；手动停止、读取失败不弹保存询问。UI 每场询问一次，使用结束时的摘要快照。保存为 PNG 或 HTML；图片按前排屏幕顺序排布，长轴分页；未知站位另列，避免丢失事件；HTML 对所有内容转义并附完整摘要。

开发阶段保留 sessions 原始诊断日志；拒绝保存不生成行动轴文件。文件对话框取消后可从按钮再次保存。没有添加自动删除诊断样本的行为。

验证：92 项测试通过，包含玩家行动中破盾更新、敌方排队游标、连续两动期间保持预告、多敌人独立状态、默认收起/展开不丢记录、结束询问去重、拒绝保存、HTML 转义及 PNG 分页。已生成并目视检查中文 PNG 示例 sessions/axis-preview.png。此轮预告生命周期仍需游戏实测确认极短队列切换的采样表现。
