## 后续修正：所有按钮伤害纳入指令，鬼神化直接观测状态

用户补充要求后，小按钮不再从指令统计排除。单独行保留 instant id，damage_group_id 则先使用共享待执行指令桶，再在普通行动出现时回填同一实际指令 id；回填以更新原事件完成，不重复计数。未知指令伤害暂独立保留。原始命中仍仅将明确的对敌伤害计入，治疗和非伤害效果不冒充伤害。

实录 player-probe-005820：STezuka03 的 _reinforcedModeUsedCount（508/int32）从 0 增至 1，_reinforcedModeTurn（500/int32）从 0 增至 3；ActionEntry 队列始终为空。因此无法仅凭队列捕获鬼神化。PlayerTransitions 按类型元数据验证使用次数和 _isAnotherCardForm（496/bool），对状态边沿生成零伤害、不占指令记录，普通采样不重复；风格 label 变化也记录。连接、暂停、采样中断后只建立基线，不臆造此前发动。

FormationReader 优先选择元数据明确的全队 playerList，避免 frontPlayerList/subPlayerList 并存导致歧义；采集包含后排。Saki 的技能选择界面入口无需额外 UI 操作：实际角色状态变化才是记录依据。采用用户允许的单列行形式，没有强行和之后技能合并。

100 项测试通过，新增真实 Saki 前后状态夹具、空行动队列下只记录一次、风格/形态切换、全队列表选择及按钮伤害归并检查。跨角色形态机制仍需实测扩充。
